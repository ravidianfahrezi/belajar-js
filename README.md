# Roadmap Belajar Web dengan JavaScript (Versi Skripsi)

Workspace ini disiapkan untuk mengikuti roadmap belajar Web Development dengan JavaScript yang berfokus pada penyelesaian skripsi.

## 📝 Checklist Progress

### FASE 0 | Persiapan alat kerja (1 minggu)
- [x] Terminal: berpindah folder, membuat dan menghapus file, menjalankan perintah
- [x] Git dan GitHub: init, add, commit, branch, merge, push, pull, dan cara membuat pull request
- [ ] Menginstal Node.js, memahami npm (install, scripts, package.json)
- [ ] Browser DevTools: tab Console, Elements, Network, dan Sources

### FASE 1 | JavaScript inti (3-4 minggu)
- [ ] Variabel (let, const), scope, tipe data, falsy dan truthy
- [ ] Function: anonymous, arrow function, callback
- [ ] Closure dan konsep this
- [ ] Array dan method-nya: map, filter, reduce, find, sort
- [ ] Object, destructuring, spread dan rest operator
- [ ] OOP: class, inheritance, getter dan setter
- [ ] JavaScript Modules: import dan export
- [ ] Asynchronous: callback, Promise, async/await, penanganan error dengan try/catch
- [ ] Standard library: Date, JSON, Intl, dan Regex
- [ ] Unit test dasar dengan Jest
*Proyek: Aplikasi to-do list atau pengelola pengeluaran berbasis terminal (Node.js)*

### FASE 2 | DOM dan Web API (2 minggu)
- [ ] Memilih dan mengubah elemen DOM, membuat elemen secara dinamis
- [ ] Event handling dan event delegation
- [ ] Fetch API: GET dan POST, membaca JSON, menangani loading dan error
- [ ] Form: validasi di sisi client dan pengelolaan input
- [ ] localStorage dan sessionStorage
- [ ] Flexbox dan Grid untuk layout responsif
*Proyek: Aplikasi pencarian film atau cuaca yang mengambil data dari API publik*

### FASE 3 | Node.js, Express.js, dan database (5-6 minggu)
- [ ] Node.js: modules (ESM dan require), fs, path, events, dan environment variable
- [ ] Express: routing, middleware, request dan response, penanganan error
- [ ] Desain REST API: method HTTP, status code, penamaan endpoint, pagination
- [ ] Struktur proyek yang rapi: route, controller, service
- [ ] Validasi input di server (Zod atau Joi)
- [ ] Database SQL (MySQL atau PostgreSQL) dan ORM seperti Prisma
- [ ] Autentikasi: hashing password (bcrypt), session atau JWT, otorisasi berdasarkan peran
- [ ] Keamanan dasar: CORS, rate limiting, helmet, dan pengelolaan secret di .env
- [ ] Logging dan test untuk endpoint penting
*Proyek: REST API blog atau manajemen kontak lengkap dengan register, login, CRUD, dan validasi*

### FASE 4 | React esensial (2-3 minggu)
- [ ] Component, JSX, dan JavaScript di dalam JSX
- [ ] Props dan nested component
- [ ] Conditional rendering dan rendering list (key)
- [ ] Event handler dan form
- [ ] State dan cara React melakukan render ulang
- [ ] Side effect dengan useEffect dan pengambilan data dari API
- [ ] Context untuk berbagi state
*Proyek: Dashboard kecil yang mengambil data dari API Express di Fase 3*

### FASE 5 | Next.js (3-4 minggu)
- [ ] Routing berbasis folder (App Router), layout, dan navigasi
- [ ] Server Component vs Client Component
- [ ] Pengambilan data, caching, dan revalidation
- [ ] Route Handler (API) dan Server Actions
- [ ] Autentikasi dan proteksi halaman
- [ ] Metadata dan SEO, optimasi gambar dan font
- [ ] Menghubungkan Next.js ke API Express atau langsung ke database
*Proyek: Bangun frontend skripsimu dengan Next.js*

### FASE 6 | Penyelesaian, pengujian, dan deployment (2-4 minggu)
- [ ] Semua fitur inti (MVP) berjalan dari awal sampai akhir
- [ ] Pengujian black box dengan tabel kasus uji, dan UAT dengan pengguna nyata
- [ ] Konfigurasi environment untuk development dan production
- [ ] Domain, HTTPS, dan hosting
- [ ] README yang jelas dan repositori GitHub yang rapi
- [ ] Backup database dan data demo untuk sidang
*Proyek: Sistem skripsi yang bisa diakses publik dan siap didemokan*

### Checklist web yang proper (sepanjang perjalanan)
- [ ] HTML semantik dan aksesibilitas
- [ ] Desain responsif dengan pendekatan mobile-first
- [ ] Performa: ukuran gambar, lazy loading, skor Lighthouse
- [ ] SEO dasar: title, meta description, heading, sitemap
- [ ] HTTP: method, status code, header, cookie
- [ ] Keamanan: XSS, CSRF, SQL injection, jangan commit .env
- [ ] Validasi input di server
- [ ] SQL dan desain database: relasi, index, migrasi
- [ ] Testing otomatis untuk logika dan endpoint penting
- [ ] Commit Git yang kecil dan bermakna

Semangat menyusun skripsi dan belajar!
